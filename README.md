# 🚀 TaskFlow

A full-stack task management application built with React and Node.js.

## ✨ Features

- Create tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- REST API backend
- Responsive user interface

## 🛠️ Technologies Used

### Frontend
- React
- Vite
- Axios
- CSS

### Backend
- Node.js
- Express.js
- CORS
